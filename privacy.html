KINDLE FAMILY CALENDAR

隱私權政策

更新日期：2026 年 10 月 9 日

存取與用途

本程式以 Google OAuth 取得 calendar.events.readonly 權限，只讀取擁有者指定的家庭日曆，用於在自己的家庭網路看板顯示安排。Google 權限可涵蓋帳號可存取的日曆，但程式固定查詢單一日曆，並核對日曆名稱。

查詢範圍為本週週日到今天起第八天之前，最多十四天。向 Google 取得活動識別碼、狀態、名稱、開始與結束時間，並將重複活動展開；不要求活動備註、地點、參與者或會議連結。

儲存與安全

本機或 NAS 保存 OAuth 憑證及更新權杖，以便在既有授權下定期同步。行程快照只保留活動識別碼、名稱、開始、結束、全天旗標，以及同步時間與涵蓋日期。憑證和快照不放在這個公開說明網站。

每次成功同步以新快照取代舊快照；同步失敗時保留最後成功資料，不會自動刪除。停止使用後資料仍可能留在擁有者裝置或自行建立的備份，須由擁有者自行刪除。本程式不建立中央雲端行程資料庫。

分享與限制使用

日曆資料用於擁有者家中的顯示服務；可存取該家庭網路服務的人可能看到看板內容。程式不將 Google 使用者資料提供給廣告商、資料仲介、GitHub Pages 或生成式 AI 訓練服務，不銷售資料，也不以資料建立廣告輪廓。

本程式對 Google API 資料的使用與傳輸遵循 Google API Services User Data Policy，包括 Limited Use 要求。

撤銷授權與刪除

擁有者可以在 Google 帳戶的第三方連線設定撤銷應用程式存取權，並停止本機或 NAS 服務。撤銷授權不會自動清除既有快照；如要移除所有本機資料，還須刪除裝置上的憑證、快照及自己的備份。

公開說明網站

本說明網站沒有日曆 API、登入表單、分析追蹤碼或廣告。若託管於 GitHub Pages，GitHub 會依其安全措施記錄訪客 IP；詳見 GitHub Pages 說明與 GitHub 隱私權聲明。
